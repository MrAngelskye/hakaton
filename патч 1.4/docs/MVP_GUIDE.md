# Сценарии MVP 1.5

1. Мастер выбирает участок и оборудование из единого каталога, назначает сотрудника/бригаду, срок, приоритет, график и при необходимости норматив/фото до ремонта.
2. Сотрудник видит назначение, принимает, ставит в очередь или отклоняет с причиной. Бригадное назначение появляется у всех действующих участников.
3. Сотрудник начинает работу; пауза требует причины. Неполный результат можно отправить для уточнения. Материалы берутся из каталога с ценой и единицами; черновик сохраняется на устройстве.
4. ИИ предварительно проверяет отчёт, если подключён. При недоступности модели отчёт поступает на ручную приёмку. Время выполнения и ожидание проверки учитываются отдельно.
5. Мастер сравнивает данные и фото до/после, ставит оценку и комментарий, принимает или возвращает на доработку. Внеплановый наряд не закрывается без фото результата.
6. Администратор редактирует каталоги и доступ. Руководитель читает сводки и историю. Рейтинг сотрудников/бригад и расход рассчитываются сервером за выбранный период.

Мобильный веб адаптирован к backend 1.5. Для PWA нужны HTTPS и проверка реальным телефоном. Учебная история загружается через `run_demo.py --dataset`; пароль полного набора `DemoOnly-2026!`. [Запуск](../README.md), [объединение](CONSOLIDATION.md), [пакет БД](../../database/README.md).
