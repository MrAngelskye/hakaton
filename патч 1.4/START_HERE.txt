НАРЯДAI 1.4 — ОБЛАКО И ДОМАШНИЙ ИИ

БЫСТРО ПОСМОТРЕТЬ МОБИЛЬНЫЙ/ВЕБ MVP НА КОМПЬЮТЕРЕ:
Установите Python 3.12 (64 бит). install_web.bat → start_web.bat.
Откройте http://127.0.0.1:8841. Локальное демо без ИИ, отдельная БД demo_data.
Демо: master / worker1 / admin, пароль 1234.
Веб-установщик не устанавливает Qt/PySide6 и использует отдельную .webvenv.
Мобильная установка на Android требует HTTPS. Это PWA, сборки APK нет.
Сценарии и ограничения: docs/MVP_GUIDE.md. Основные настройки облака ниже.

Сервер приложения: Render. Данные и фото: Supabase.
ИИ: AnythingLLM и локальная модель на ПК владельца.
Два клиента работают из разных домов по одному HTTPS-адресу, без VPN.

ВАЖНО ПРИ РАСПАКОВКЕ:
Используйте короткую папку, например C:\Users\ВашеИмя\NaryadAI.
Не вкладывайте длинные папки репозитория друг в друга: PySide6 может превысить
предел длины пути Windows. После неудачной установки распакуйте архив заново
в короткую папку; частичную .venv не переносите. Затем запустите install.bat.

ПОРЯДОК ДЛЯ ВЛАДЕЛЬЦА:
1. Установить Python 3.12 (64 бит), распаковать, запустить install.bat.
2. Настроить Supabase и Render по README.md. generate_cloud_secrets.bat
   создаёт два отдельных секрета; их значения вводить в Environment Render.
3. Установить AnythingLLM и Ollama, выбрать/скачать модель.
4. configure_server.bat -> создать отдельное пространство -> check_ai.bat.
5. configure_worker.bat -> адрес Render и AI_WORKER_TOKEN -> start_worker.bat.
6. start_client.bat -> адрес Render -> роль сотрудника -> worker4.

ПОРЯДОК ДЛЯ ТОВАРИЩА:
1. Установить Python 3.12 (64 бит), распаковать чистый архив, install.bat.
2. start_client.bat -> тот же адрес Render -> роль мастера -> master.
3. Пароль получить от владельца: в облаке это BOOTSTRAP_PASSWORD, не 1234.

Адрес вводится один раз; дальше подключение автоматическое.
Первое подключение после простоя сервера может занять около минуты.
Если адрес изменился: configure_client.bat.

Секреты не пересылать в чат/GitHub. Товарищу не нужны ключ базы, AnythingLLM
или ключ обработчика. Не пересылать свою настроенную папку целиком.
Окно start_worker.bat, AnythingLLM и Ollama должны быть открыты на ПК владельца.
Если ИИ выключен/не ответил, отчёт поступит мастеру на ручную проверку.
Оценка ИИ предварительная. Окончательную оценку ставит мастер.

start.bat — локальное демо. start_server.bat — прежний локальный сервер.
Для облачного теста использовать start_client.bat и start_worker.bat.
Старый проект и его локальные данные не заменяются и не удаляются.
