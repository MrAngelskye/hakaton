# Совместимость БД

Версия 1.5 использует каноническую схему 002 для SQLite и PostgreSQL. Клиенты обращаются к одним каталогам по ID; старая дополнительная схема `reference_items` не используется.

[Пакет с учебной SQLite, фото, PostgreSQL baseline, миграцией и импортёром](../../database/README.md). [API и безопасная миграция](DATABASE_V2.md). [Состав объединения](CONSOLIDATION.md).

Приложение обновляет существующую БД с сохранением записей и паролей. Для отдельной демонстрации `tools/import_demo.py --data-dir demo_dataset` загружает существующий архив только в новую папку; повтор не перезаписывает действия. PostgreSQL импортируется штатным `load_postgres.py` пакета, который применяет 002.
