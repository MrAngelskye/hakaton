# Визуальный стиль и обратная связь НарядAI

Обновление для версии ПК (PySide6) и мобильного веб-приложения/PWA. Предприятие: АО «Костанайские Минералы». Основная палитра остаётся в существующей системе: тёмно-синий каркас, белые рабочие поверхности, синий для основного действия. Красный означает ошибку, зелёный — подтверждение; статус дополнительно объясняется текстом.

Проверенные пары цветов веб-интерфейса: синий `#155BA7` на белом — 6,80:1; вторичный текст `#52647B` на `#F1F4F8` — 5,49:1; красный `#B52328` на `#FFF1F1` — 5,90:1; зелёный `#1C674C` на `#EAF5EE` — 6,07:1. Эти пары превышают порог 4,5:1 для обычного текста WCAG AA.

## Решения с трёх сторон

1. **Работа сотрудника и мастера.** Иконки имеют одинаковые размеры и центрирование. Новые разделы получили собственные символы. Основное действие видно сразу; ожидание, ошибка и успех объясняются рядом с действием. Ошибка сохраняет контекст формы и допускает осознанный повтор.
2. **Мобильное использование и доступность.** Навигация сохраняет четыре вкладки; кнопки без текста имеют область нажатия 48 × 48 px. На узком экране действия администратора переносятся, а подписи и ошибки могут занимать несколько строк. Сохранены клавиатурное управление, видимый фокус, подписи полей и уведомления для экранных дикторов. Системная настройка уменьшения движения и настройка приложения отключают декоративные анимации, оставляя текстовые статусы.
3. **Производительность и надёжность.** Короткие переходы запускаются при явной навигации. Фоновый опрос сервера не запускает анимацию перехода и не заменяет страницу с ожидающей операцией. Индикатор отправки отражает настоящий запрос; повтор не выполняется автоматически. Идентификаторы запросов, сохранение черновиков и фиксация уже отправленного отчёта продолжают действовать.

## Что видно пользователю

- Каркас загрузки при первоначальном подключении рабочего пространства.
- Индикаторы в кнопках входа, сохранения, отправки отчёта, расчёта аналитики, отправки сообщения ИИ и загрузки документа.
- Статусы загрузки истории наряда, истории оборудования, документов и фотографий; ожидание ответа ИИ.
- Короткое появление подтверждений и ошибок без встряхивания экрана.
- Одинаковые стрелки выбора и раскрытия, центрированные кнопочные SVG и согласованные отступы.
- В версии ПК — индикаторы настоящей фоновой работы чата и локального распознавания речи, явные стрелки календаря, выбора и числовых полей. Синхронные операции хранилища не переводились в потоки: это отдельная работа с серверным взаимодействием.

## Проверка обновления

Автоматические проверки используют демонстрационные ответы сервера и отдельную тестовую базу. Они не записывают звук и не изменяют рабочие данные.

```text
node tests/check_ui_polish.js
node tests/check_voice_integration.js
node tests/check_voice.js
node tests/check_web_rpc.js
node tests/check_browser_notifications.js
python -m unittest discover -s tests -p "test_*.py"
```

Для браузерных проверок нужен установленный Playwright и браузер; переменная `NARYADAI_TEST_BROWSER` позволяет указать исполняемый файл браузера. `NARYADAI_UI_SCREENSHOTS` указывает каталог для скриншотов. Физическое Android-устройство, реальные серверные задержки и точность распознавания речи требуют отдельной проверки командой перед показом MVP.
