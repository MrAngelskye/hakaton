# НарядAI — кейс №1 АО «Костанайские минералы»

**Эта ветка: `codex/production-db-open-data`, из `cloud-1.4`. Рабочий режим без автозаполнения демо, миграции 002–004.**

Начните с [инструкции рабочей БД](database/production/README.md): подтверждённые открытые справочники, 19 аккаунтов с вымышленными славянскими ФИО с индивидуальными локальными паролями, 20 шаблонов и 25 лицензированных фотографий. Реальные сотрудники, инвентарные номера и производственная история не предоставлены и не выдумываются. Исторические учебные архивы ниже сохранены для отдельной демонстрационной среды и автоматически не импортируются.

Ветка объединяет последнюю серверную логику, ПК-приложение, мобильный веб-интерфейс/PWA, KM-айдентику, анимации, документацию и пакет учебной базы данных. Папка `патч 1.4` сохранена, чтобы существующие пути запуска и Render не менялись.

- [Запуск приложения и демонстрации](патч%201.4/README.md).
- [База данных: PostgreSQL, SQLite и импорт](database/README.md).
- [Полный пакет БД с 608 нарядами и 705 учебными фото](database/naryadai_database.zip).
- [Состав объединения и проверенные ограничения](патч%201.4/docs/CONSOLIDATION.md).
- [Требования, анализ и план развития](docs/project/README.md).

Приложение и БД находятся в одной ветке. Реальное развёртывание PostgreSQL/Storage и подключение модели выполняются отдельно на инфраструктуре команды. Все данные и фото из учебного пакета синтетические.
