# База НарядAI — кейс №1, «Костанайские минералы»

Полный пакет: [скачать naryadai_database.zip](naryadai_database.zip). В архиве схема PostgreSQL, импорт данных, генератор, SQLite для просмотра и 705 учебных JPEG. Распакуйте архив в отдельную папку и откройте `naryadai_database/README.md`.

SQL и скрипты также доступны для просмотра в [naryadai_database/](naryadai_database/). Готовая папка `generated/` с SQLite, JSON, seed SQL и изображениями находится в архиве: после распаковки все скрипты работают с ней по умолчанию.

Данные: 608 нарядов, 655 версий отчётов; история 04.07.2026–03.10.2026; 4 участка, 25 единиц оборудования, 2 мастера, 15 исполнителей, 3 бригады, 20 кодов дефектов, 40 материалов.

Все сведения, изображения и оценки ИИ учебные. Реальные данные предприятия и подключение к облаку нужно настроить отдельно.

Интеграция подготовлена для `cloud-1.4`, папки `патч 1.4`, исходного коммита `836961552f2389042687ffd1df4b7f512387cc0e`. Для установки примените `apply_integration.py` по инструкции; он проверяет исходники и сохраняет резервные копии. Само размещение пакета в GitHub не запускает импорт БД.

Проверено локально на PGlite и через API: схема и повторный импорт, права, создание наряда, пауза, отчёт с фото и принятие мастером. Условия и ограничения проверки — [validation.json](naryadai_database/validation.json).

SHA-256 полного архива: `1d5f9682ba04a4dbe8973acbf12a8ebe3232178ce11de4e019ffb1cdc5af367a`.
