# НарядAI — Android приложение ByteX

Flutter-клиент к существующему серверу «НарядAI» для АО «Костанайские Минералы». Общая БД, права доступа и анализ отчётов остаются на Python-сервере. Qwen не загружается на телефон.

## Что работает

- Сотрудник: доступные и назначенные наряды, выбор времени из свободных интервалов, начало/пауза/продолжение, очередь и отказ с причиной, личный график, отчёт с материалами и фото, доработка и результаты приёмки, статистика и уведомления.
- Мастер: создание и назначение наряда, приоритет и переназначение с причиной, просмотр загрузки сотрудников, настройка смены, отчёты и заключение ИИ, приёмка с оценкой и комментарием либо возврат на доработку.
- Администратор: отдельный вход через мобильную веб-панель в браузере. Пароли и токены приложения в ссылку не передаются.
- Черновики отчётов и нового наряда сохраняются на устройстве, включая прикреплённые фото отчёта. Последние полученные данные доступны при потере связи. Отправка и изменение серверных нарядов требуют подключения; автоматической фоновой отправки нет.
- Русская диктовка на Android через Vosk без передачи аудио внешним сервисам. Проверьте и отредактируйте текст перед добавлением в отчёт.
- Отдельная демонстрация с явно вымышленными данными, не изменяющая общую БД и не имитирующая настоящее подключение к Qwen.

## Запуск и сборка

Нужны Flutter 3.47.6, Java 17, Android SDK 36. Минимальная версия телефона — Android 7.0 (API 24). Flutter использует NDK 28.2.13676358. Команды из папки `mobile`:

```sh
flutter pub get
python tool/prepare_voice.py
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --release
```

APK появляется в `build/app/outputs/flutter-apk/app-release.apk`. Голосовая модель скачивается с официального сайта Vosk, проверяется по SHA256 и включается в APK. Модель и результаты сборки исключены из Git.

По умолчанию используется `https://hakaton-cj24.onrender.com`. Адрес можно изменить на экране входа или при сборке через `--dart-define=SERVER_URL=https://your-server.example`. Для общего сервера требуется HTTPS. Разрешённый адрес локального Android-эмулятора: `http://10.0.2.2:8000`; для него потребуется отдельная отладочная конфигурация cleartext. Производственная сборка использует HTTPS.

Текущая APK для тестирования подписывается отладочным ключом сборщика. Для стабильных обновлений и публикации в магазине команда должна настроить собственный постоянный ключ подписи. Android резервное копирование приватного хранилища отключено. Пароль не сохраняется, токен и текст черновиков хранятся через Android Keystore.

## Первый тест на телефоне

1. Установите APK и войдите реальным аккаунтом сотрудника или мастера. Для просмотра интерфейса доступна отдельная демонстрация.
2. Администратор предварительно заполняет справочники и создаёт аккаунты в веб-панели. Пустые справочники приложение не заменяет придуманными производственными данными.
3. Мастер выдаёт наряд, сотрудник начинает его и заполняет отчёт. Проверьте камеру, галерею и разрешение микрофона именно на вашем устройстве.
4. Отключите интернет, измените отчёт, вернитесь назад, снова откройте форму. Черновик должен сохраниться. После подключения отправьте его вручную.
5. Мастер проверяет фото, заключение ИИ и принимает отчёт либо возвращает его с комментарием. У сотрудника обновляются статус и результаты.

В MVP уведомления обновляются внутри открытого приложения. Системные push-уведомления, фоновая синхронизация, полная автономная работа и геолокация не включены. Качество распознавания зависит от шума; названия оборудования и числа требуют проверки. Решение о безопасности работ, допусках и приёмке принимает ответственный специалист предприятия.

Локальная модель `vosk-model-small-ru-0.22` распространяется по Apache 2.0: https://alphacephei.com/vosk/models . Библиотека Vosk: https://github.com/alphacep/vosk-api .
