# Отдельный набор для обучения и проверки ИИ

Этот набор относится к **кейсу №1 «НарядAI» АО «Костанайские минералы»**. Он лежит в отдельной ветке `codex/ai-training-dataset` и не загружается в приложение автоматически.

**Наряды, люди, оборудование, ремонты, нормы и ответы вымышлены.** Это материал для разработки ИИ, а не настоящая история предприятия. Паролей здесь нет; существующие аккаунты и пароли рабочей БД не меняются.

## Что готово

Скачайте [готовый архив](naryadai_ai_training.tar.xz). В нём полный набор без сокращения; формат TAR.XZ уменьшает размер примерно до 0,8 МБ. Состав и контрольные суммы — в [package_manifest.json](package_manifest.json). Распаковать можно стандартным Python без дополнительных библиотек:

```sh
python -m tarfile -e naryadai_ai_training.tar.xz training_data
```

Оборудование разделено между обучением, настройкой и тестом целиком. История одного объекта не попадает сразу в несколько частей. История в JSONL содержит только сведения, известные до выдачи текущего наряда. Вход модели не содержит ФИО, логинов, итогового статуса, оценок или ответов мастера.

В наборе есть недописанные отчёты, неверные коды неисправностей, неподходящие материалы и избыточный расход, пропущенные вложения и нарушения времени. Учебные ответы: 188 `accepted`, 116 `accepted_with_remarks`, 196 `rework_required`. Правила выставления ответов описаны в [DATASET_CARD.md](DATASET_CARD.md).

## Как использовать с PostgreSQL

Создайте отдельную учебную БД и выполните из распакованной папки:

```sh
createdb naryadai_training
psql -d naryadai_training -v ON_ERROR_STOP=1 -f exports/postgresql.sql
psql -d naryadai_training -v ON_ERROR_STOP=1 -f analytics.sql
```

Таблицы создаются в схеме **`naryadai_ai_training`**. Скрипт рассчитан на пустую схему и не удаляет существующие таблицы. Это отдельная учебная структура, не миграция схемы приложения. Не задавайте рабочий `DATABASE_URL` ради этого импорта.

## Как пересоздать пакет

Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются. Из корня репозитория:

```sh
python database/ai_training/prepare.py --outputdir training_output --archive naryadai_training.tar.xz
```

Выберите новые пути: существующие файлы не перезаписываются. Можно также задать имя архива с расширением `.zip`. Seed по умолчанию `20261008`; данные при нём воспроизводимы. Отдельные команды:

```sh
python database/ai_training/build_dataset.py --output training_output/dataset.json
python database/ai_training/export_dataset.py --dataset training_output/dataset.json --outputdir training_output/exports
python database/ai_training/validate_dataset.py --dataset training_output/dataset.json --exports training_output/exports --report training_output/validation_report.json
```

Для отрицательных проверок задайте `NARYADAI_TRAINING_DATASET` и `NARYADAI_TRAINING_EXPORTS` путями к своим файлам, затем запустите `python -m unittest discover -s database/ai_training -p test_validate_dataset.py`.

## Что этот пакет позволяет проверить

Сравнение отчёта с нарядом, контроль расхода и сроков, поиск повторных неисправностей, простои по сменам и запросы к истории оборудования. Четыре закономерности рассчитаны из записей и сохранены в `dataset.json → metadata.analytics_patterns`.

**Фотографий в этом наборе нет.** `photo_evidence` имитирует только наличие и время вложений. Ответ по изображению всегда `not_assessed`; вывод модели требует проверки мастером. Отдельный каталог открытых фотографий в `database/production/photo_dataset` не связан с этими нарядами и не является размеченной историей ремонта.

Модель пока не обучена. Для обучения анализу настоящих фотографий нужны реальные снимки оборудования с разрешением на использование и разметка специалиста. Полные ограничения и порядок работы с RAG — в [описании набора](DATASET_CARD.md).
