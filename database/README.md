# НарядAI — кейс №1 АО «Костанайские минералы»

Объединённая ПК- и веб/PWA-версия приложения 1.5 и миграция БД 002 внесены в `патч 1.4/`. [Что исправлено](CHANGES.md), [инструкция и API](../%D0%BF%D0%B0%D1%82%D1%87%201.4/docs/DATABASE_V2.md).

[Скачать полный пакет naryadai_database.zip](naryadai_database.zip). В нём схема PostgreSQL, миграция, импортёр, генератор, SQLite и 705 учебных JPEG. Папка `generated/` находится в архиве; для первого запуска повторная генерация не нужна. [Инструкция пакета](naryadai_database/README.md).

Набор: 608 нарядов, 655 версий отчётов, история 04.07.2026–03.10.2026, 4 участка, 25 единиц оборудования, 2 мастера, 15 работников, 3 бригады, администратор и руководитель, 20 дефектов, 40 материалов. Все данные, изображения и оценки модели синтетические.

Импортёр применяет baseline и миграцию 002. Новая версия приложения обновляет существующую БД без подмены её учебными данными; инструмент `tools/migrate_sqlite_to_postgres.py` переносит SQLite с резервной копией в пустую PostgreSQL.

[Результаты проверок](naryadai_database/validation.json): SQLite, API через PGlite/psycopg, SQL-ограничения, Qt, импорт, установщик и перенос данных. Облако PostgreSQL/Storage, параллельная нагрузка, Android push и точность реального ИИ требуют проверки на инфраструктуре команды. Публикация кода не разворачивает БД.

SHA-256 архива: `d36b1afb2c11f9a8c2f3a9da3827558d6fcb07da9a86d4435091ad0f96761a8e`.

Для отдельной локальной демонстрации из папки приложения: `python run_demo.py --dataset --data-dir demo_dataset`. Пароль полного набора `DemoOnly-2026!`. Импорт существующего архива разрешён только в новую папку; инструкция в [README приложения](../патч%201.4/README.md).
