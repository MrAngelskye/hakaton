# Мобильный и веб-интерфейс НарядAI 1.5

Клиент работает на том же Python/FastAPI API и БД 002, что и ПК-приложение. Корень `/` — приложение, `/web/*` — общедоступная оболочка. Наряды, каталоги, отчёты, аналитика и фотографии защищены авторизацией. ИИ рекомендует; мастер принимает решение.

Сотрудник видит личные и бригадные задания, принимает/ставит в очередь/отклоняет с причиной, запускает и приостанавливает работу, отправляет форму с материалами и до пяти фото. Черновик хранится в IndexedDB текущего браузера, удаляется при выходе. Потерянный ответ на отправку можно повторить вручную с тем же ID без второго отчёта.

Мастер назначает сотрудника/бригаду, выбирает оборудование и норматив, прикладывает фото до ремонта, переназначает и отменяет задания, сравнивает фото до/после, принимает отчёт с собственной оценкой или возвращает с комментарием. Администратор редактирует канонические каталоги. Руководитель читает отчёты и аналитику; изменения запрещены сервером.

Аналитика получает данные всей БД за выбранный период; список нарядов по умолчанию показывает активные работы и 14 дней истории. В истории оборудования используется ID и инвентарный номер. Рейтинг рассчитывается сервером, отдельно для сотрудников и бригад.

## Запуск

Из папки приложения: `python run_demo.py --dataset --data-dir demo_dataset`. Учебный пароль — `DemoOnly-2026!`. Без `--dataset` новая маленькая демо-база использует пароль `1234`. Подробнее в [общей инструкции](../README.md).

Для установки PWA нужны HTTPS или localhost. HTTP-адрес в локальной сети позволяет открыть страницу на телефоне, но не гарантирует PWA и работу камеры. Установка PWA не создаёт APK. Реальный Android, HTTPS, камера и push требуют отдельной проверки.

Service worker сохраняет только общедоступную оболочку; API и фото не кэшируются. Без сети доступны оболочка и сохранённый черновик текущего сеанса; вход, обновление заданий и отправка требуют сервера. Автоматической фоновой отправки нет.

## Проверка

`python -m unittest discover -s tests -p "test_*.py"` проверяет сервер, миграцию, полный цикл и Qt. `node --check web/app.js`, `node --check web/sw.js` проверяют синтаксис. `node tests/check_web_rpc.js` проверяет повтор запроса после потерянного ответа и HTTP 503/400. Для тестов установите `requirements-test.txt`.
